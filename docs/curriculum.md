# Учебный план RoboEasy — «Робототехника с нуля»

Статус: **черновик на утверждение** (фаза 13.2). Названия уроков — на русском; тексты на kk/ru/en пишутся в фазе 14 вместе с контентом.

## 1. Принципы

1. **Без набора можно.** Основной путь проходится на виртуальном роботе в симуляторе. Задания `real_robot` — бонус, помечены 🤖 и не блокируют прогресс.
2. **Сразу действие.** Урок 5–10 минут, 3–8 шагов. Теория — до ~120 слов на шаг, дальше «сделай сам».
3. **Автопроверка.** Задания `code`/`predict`/`debug` проверяет симулятор (зона финиша, точки маршрута, столкновения, время, использованные конструкции, срабатывание датчика). Попыток сколько угодно, без штрафа.
4. **ИИ — наставник.** Подсказки ступенями (вопрос → на что посмотреть → фрагмент), полного решения в учебном режиме нет.
5. **Без давления.** Стрики и XP мотивируют, но не стыдят.

Каждый урок начинается с цели («Сегодня ты научишь робота…») и заканчивается итогом («Теперь ты умеешь…»).

```
   ┌──────▼───────┐             ┌──────▼───────┐
   │ 3. Блоки     │             │ 2. Сборка    │  ← параллельно, не обязателен для виртуального пути
   └──────┬───────┘             └──────┬───────┘
   ┌──────▼───────┐                    │
   │ 4. Датчики   │                    │
   └──────┬───────┘                    │
   ┌──────▼───────┐             ┌──────▼───────┐
   │ 5. Навигация │             │ 7. Механизмы │
   └──┬────────┬──┘             └──────┬───────┘
      │ ┌──────▼──────┐                │
      │ │ 6. Python   │                │
      │ └─────────────┘                │
      └───────────────┬────────────────┘
               ┌──────▼───────┐
               │ 8. FLL       │
               └──────────────┘
```

**Отличия от исходного списка (предлагаю):**
- «Сборка» — **параллельный** трек, а не шаг между «Стартом» и «Блоками». Иначе ученик без набора застревает на втором треке. Виртуально он учит детали и сборку по 3D-инструкциям, физическая сборка — 🤖.
- «Python» открывается после «Датчиков» (нужны все базовые конструкции), а не только после «Блоков». Рекомендуется после «Навигации», но не обязательно.
- В «FLL» входят все четыре части соревнования (Core Values, Innovation Project, Robot Design, Robot Game), а не только заезды — иначе команда не готова к защите.

| 2 | Сборка | после «Старта» | 5 / 18 | ~2,5 ч | ~70 % (сборка — 🤖) |
| 3 | Программирование блоками | после «Старта» | 5 / 25 | ~3,5 ч | 100 % |
| 4 | Датчики | после «Блоков» | 5 / 20 | ~2,5 ч | 100 % |
| 5 | Навигация и точность | после «Датчиков» | 4 / 13 | ~2 ч | ~90 % |
| 6 | Python | после «Датчиков» | 5 / 15 | ~2 ч | 100 % |
| 7 | Механизмы и насадки | после «Сборки» + «Датчиков» | 4 / 11 | ~1,5 ч | ~60 % |

Итого 123 урока, ~17 часов практики по 5–10 минут (без повторений и тестов). Первая версия намеренно компактная: добавлять уроки проще, чем убирать. Возраст: основной путь рассчитан на 9–12 лет; для 13–16 и взрослых — тест на входе и более быстрые подсказки.

## 5. Тест на входе

10 заданий, ~8 минут, адаптивно (после двух ошибок подряд — стоп):
1–2. `robot-basics`: что делает мотор / датчик (Q)
3. `motion`: сколько проедет робот за 2 оборота колеса 5,6 см (Q, число)
4. `sequence`: P — где финиш
5. `loops`: короче ли программа с циклом (Q)
6. `conditions`: D — робот не останавливается у стены
7. `sensor-color`: C — стоп на линии
8. `gyro`: Q — зачем сбрасывать угол
9. `python`: Q — что делает `await`
10. `gears`: Q — шестерня 8 → 24 зуба: быстрее или сильнее

Результат: «Начни с трека X, урока Y» + список навыков, которые засчитаны. Пройденные тестом уроки отмечаются «знаю», XP за них не начисляется.

## 6. Повторение

Раз в 2–4 дня — 3 коротких задания (2–3 минуты) по навыкам, где были ошибки или давно не было практики (интервалы 1 → 3 → 7 → 14 дней). Повторение засчитывается в дневную цель.
